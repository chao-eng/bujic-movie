## 本次更新

### 🔍 新增：资源搜索与下载

把 Prowlarr 的核心产品设计重写进本项目，形成「定义库 → 站点 → 聚合搜索 → 推送到下载器」的完整链路。

- **站点接入**支持两类：通用协议（Torznab / Newznab）与 Cardigann 定义（兼容 Prowlarr 定义格式）。定义文件不随仓库分发，运行时从上游同步或本地导入 YAML。
- **聚合搜索**：一次搜索多个站点，结果按种子指纹跨站合并，同一条资源不会重复出现；可按分类、做种数、大小筛选与排序。
- **一键推送**到 qBittorrent，按分类映射落盘。保存目录由下载器的分类规则决定，本系统只传分类、不传路径。
- **站点健康可见**：最近成功时间、平均耗时、连续失败与冷却状态，支持单个或全部测试（结果就地更新，不整页刷新）。
- 站点凭据用 AES-256-GCM 加密落库，读接口只返回掩码；空值表示保持原值，清除需显式操作。
- 出站请求统一走执行器：超时、重试、限速、响应体积上限与主机白名单，每一跳重定向都重新校验。

### 📡 日志通道改为 SSE

原来的 WebSocket 实时日志换成 Server-Sent Events：

- 每条消息带自增 `id`，断线重连按 `Last-Event-ID` 只补缺失的行，不再整段丢失。
- 每 15 秒心跳，既能保持代理连接，也能识别「TCP 未断但对端已死」的假活状态。
- 重连采用指数退避，并用世代号保证手动重连不会留下并行的旧连接。
- 日志含服务器路径与影片名等运行细节，因此该接口现在要求登录，不再公开。

### 🎨 前端整体重构

- 全部组件迁移到 shadcn-vue 语义 token：不再有硬编码的 `slate-*` / `amber-*` 色号，统一走 `bg-card` / `text-muted-foreground` 等；新增 success / warning / info 三个语义色。
- 原生控件换成组件（Select / Textarea / Checkbox / Switch），表单改用 `FieldGroup` + `Field`，加载态统一 `Spinner`、空态用 `Empty`、提示用 `Alert`、状态用 `Badge`。
- 修复两处会导致页面卡死的问题：路由过渡让组件树挂掉、下拉框空值让 reka-ui 抛错。
- 媒体库海报不再把 JWT 拼进 URL（原先会漏进访问日志与浏览器历史），改为带鉴权头取回。

### 🔐 浏览器扩展：导入 Cloudflare 会话

新增 Chrome / Edge 扩展 `tools/bujic-cookie-import/`，用于把浏览器里已通过人机验证的会话导回服务端。

- 不需要手填服务地址与令牌，打开插件自动复用当前 Bujic Movie 页面的登录态。
- 取 Cookie 走多条途径（含分区 Cookie 查询与真实请求头），能拿到 `cf_clearance` 这类 HttpOnly + CHIPS 的 Cookie。
- 取不到时把每一步探测结果摊在界面上，并支持手动粘贴兜底。
