## 本次更新

### 🔍 中文片名识别

中文片名在英文、韩文站点上常常搜不到，因为那些站点收录的是原名。这一版把「你输入的名字」和「站点实际收录的名字」分开处理。

- 搜索前先用 TMDB 查询原名与各地别名，然后**按站点语言选词**：中文站用中文名，韩文站用韩文名，英文站用英文名。每站仍只发一次请求。
- 搜索页会列出 TMDB 候选（海报、年份、原名、别名），**人工确认后**才去搜站点。确认结果长期复用，也可随时清除或重新识别。
- 搜索框旁有个「片名识别」开关，可以在「先确认影片」和「按原关键词直接搜」之间切换。
- TMDB 查不到或超时时照常搜索，只是退回原关键词，不会因为解析失败而卡住。

实测「鱿鱼游戏」：韩国站收到 `오징어 게임`，英文站收到 `Squid Game`，中文站收到原名。

### 🌏 站点语言筛选

搜索时可以指定只查哪些语区的站点：

- **全局筛选**：搜索框旁的语言下拉，可多选。搜「黄石」只选英文站，搜「百日谎言」只选韩文站。
- **站点级覆盖**：已添加站点可以单独配置搜索语言。像 FileMood 这种同时收录中英文资源的站点，配成「中文 + 英文」后会**用两种语言各搜一次并合并**——实测「鱿鱼游戏」的结果从 20 条增加到 40 条。

结果区顶部会显示每个站点实际收到的检索词，方便判断某个站为什么没有结果。

### 🌐 独立网络代理

网络代理从「搜索下载」里独立出来，成为一个单独的设置页：

- 一个代理地址 + 两个独立开关，分别控制**刮削**（TMDB 元数据与海报下载）和**搜索器**（定义源与站点请求）。
- 之前 TMDB 刮削完全不读设置页的代理，只认进程环境变量；现在两条链路各自可控。
- 改动保存即生效，不用重启。站点级代理仍然优先于全局开关，下载器始终直连。

### 🎨 明暗主题

- 顶栏新增太阳 / 月亮切换按钮，首次访问跟随系统，选择会记住。
- 修正亮色主题下品牌琥珀色缺失的问题：之前 `--primary` 是近黑色，导致亮色下 logo、当前菜单项和各种图标全是黑的。
- 按 WCAG 校正了对比度：所有文字与语义色都达到 AA 标准（4.5:1 以上）。

### 🛠 其它改进

- **侧栏**：修复收起后图标互相挤压的问题，收起时只留切换按钮、菜单图标居中；「搜索下载」移到第二位。
- **设置页**：「常规」更名为「刮削配置」；代理配置独立成页；删除与搜索页重复的片名识别开关。
- **站点列表**：新增「启用状态」筛选；启停改为就地更新单行，不再整表刷新（滚动位置和筛选条件都保持）。
- **弹窗**：修复站点编辑弹窗超出屏幕且无法滚动的问题。
- **语言名称汉化**：站点列表的语言筛选项从 `RU`、`DE`、`HU` 这类代码改为中文名，覆盖上游定义库中的全部 38 种语言。

### 🐛 修复

- **Cloudflare 挑战误判**：torrenttip 报「要求浏览器验证」，实际是 `sort=time` 与分页参数共现触发了 WAF 规则。改用 `sort=seeders` 即可正常搜索（已向上游 Prowlarr 定义库提交修正）。该站实测从连续失败 12 次恢复到 935ms 通过。
- **搜索相关性**：修掉三类无关结果漏网——纯数字词（`100` 命中各种编号）、子串匹配（`day` 命中 `Days`、`lie` 命中 `Lies`）、以及站点分类标错的软件资源。现在会按词边界匹配并要求过半命中，同时剔除明显不是影视的条目（但带分辨率标记的放行，避免误杀片名含这些词的真影片）。
- **切换影片时超时**：确认候选与解析共用了同一把锁导致自死锁，切换时必然卡到前端超时。已修复。
- **搜索耗时**：多 path 的站点（如 1337x 的 4 页）原先串行请求，改成并行后单站耗时从 4 个往返降到 1 个；全站搜索从 18 秒降到 6–12 秒。
- **TMDB API Key 泄露**：Go 的网络错误自带完整请求 URL，日志会把 `api_key` 写进文件。现在日志与接口返回都做了脱敏。
- **片名识别缓存**：修复两个问题——未命中的关键词每次搜索都重新问 TMDB（负缓存失效），以及缓存表只增不删（现在会定期清理 90 天未更新的行）。
- **Cardigann 模板兼容**：支持 Scriban 的 `.True` / `.False` 常量（1337x 等定义需要），并修复 filter 参数里的模板未被渲染导致 YTS 标题残留 `{{ .Result._quality }}` 的问题。
- **站点崩溃防护**：单个站点定义处理失败时不再拖垮整次搜索，只把该站标记为失败。

### ⚠️ 升级提示

如果你之前发过 TMDB API Key，建议到 [TMDB 设置页](https://www.themoviedb.org/settings/api) 重置一次。旧版本的日志会把密钥写进 `data/logs/tmdb_api.log`，本版已修复，但历史文件里可能残留。
