## 本次更新

### ⬇️ 新增：Transmission / Deluge / Aria2 下载器

之前只能推送到 qBittorrent。这一版把下载器抽象成一个统一接口，新增三种常见客户端：

- **Transmission**（RPC，2.40+）：自动完成 409 会话握手，账号密码可留空（走 RPC 白名单）。
- **Deluge**（Web UI JSON-RPC）：密码登录 + 会话 Cookie；分类走 Label 插件。
- **Aria2**（JSON-RPC）：支持 `--rpc-secret`，任务按 GID 管理。

下载器表单按类型显示字段：选 Transmission 时不会问你要 API Key，选 Aria2 时不需要用户名。任务列表把各家的状态映射成同一套词汇，暂停 / 继续 / 删除对四种客户端通用。

下载器请求仍然全部直连，不经过搜索代理。

### 📁 保存目录：能交给分类就交给分类

三种新客户端对「分类」的理解不一样，这一版按能力区分：

- **qBittorrent**：目录由分类决定。表单不再提供「下载目录」——它默认开启自动种子管理，此时接口传入的 `savepath` 会被静默忽略，留个不生效的输入框只会误导。想让某类资源落到别处，去 qB 里改那个分类的保存路径。
- **Transmission / Aria2**：没有分类概念，必须在分类映射里填下载目录，并支持一个「默认下载目录」兜底。
- **Deluge**：分类只是标签、不影响目录，映射里的目录可选。

推送前的确认弹层会显示这次实际会用哪个目录，下载记录里也存了。

（这一版先放宽过「qB 也能指定目录」，实测与文档确认 `savepath` 在自动管理下无效后收回，只保留分类。）

### 🔥 搜索结果展示热度

做种数、下载中人数、完成数多数站点其实都有，之前后端没读、界面也只有一个孤零零的「做种 N」。

- 做种数按档位表达：充足 / 偏少（标黄）/ 无人做种（标红）/ **做种未知**。站点没给数据时不再被误判成死种，也不会被「最小做种」筛掉。
- 补上「下载中」与「完成数」，并显示发布时间。合并同一资源时优先保留数据更全的来源。
- 下载确认弹窗给一段热度摘要，0 做种时直接提示换来源。
- 下载任务显示「已连接 / swarm 做种者数」，卡在 0% 的任务能一眼看出是没连上种子。

顺带修了三处数据读取：

- Cardigann 站点的下载方字段大多叫 `leechers`，之前只读 `peers`，导致几乎所有站点的「下载中」都是 0。
- 定义里声明 `encoding` 的站点（windows-1251 等）此前从未转码，标题和日期全是乱码。
- 发布时间按站点各种形态归一：unix 秒/毫秒、`3 hours ago`、`yesterday`、`12:25am`、带语言填充词的日期等；`now`/`today` 视为未知，避免整页都是「刚刚」。

### 🌐 新增官网与完整文档站

新增 `web/` 静态站点（Astro + Vue + shadcn-vue），包含产品首页与从部署到各功能模块的完整使用文档，部署在 Cloudflare Pages：

- 部署、设置、搜索下载、刮削、整理、媒体库、MCP、架构、FAQ 各一页。
- 接入了访问统计；文档目录滚动条收细，不再抢视觉。

### 🛠 其它改进

- **错误提示更具体**：站点被拦时不再一律说「拒绝或限流」，而是按状态码给出 429 调间隔、403 可能被反爬、404 检查地址。
- **登录页**标题改为「布吉影视」。
- **构建**：锁文件改用官方源、固定 Node 版本，补了 Cloudflare Pages 配置说明。
- **文档**：补充字幕翻译 Skill 的安装方式；官网与 README 加入演示视频入口。

### ⚠️ 升级提示

下载器配置新增了 `kind` 之外的能力判断。已保存的 qBittorrent 配置会自动兼容；如果你之前给 qB 的映射填过下载目录，这些目录会不再显示，因为它本来就没有生效。用 qB 请改为设置分类的保存路径。
