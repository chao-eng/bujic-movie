# ADR-010 模块开关 + 只增表迁移，保证可停用与可回滚

状态：已接受 ｜ 日期：2026-11-19 ｜ 关联：BR-40、NFR-09、NFR-12

## 背景

PRD 的止损条款要求"停用模块后既有整理/刮削/字幕链路不受影响"；运维要求降级二进制不损坏数据。现有项目所有迁移都是 `AutoMigrate`，没有版本化迁移框架。

## 选项

| 选项 | 停用粒度 | 回滚安全 | 实现成本 | 结论 |
|------|----------|----------|----------|------|
| 编译期 build tag | 重编译 | 安全 | 低 | 否决（发布两个二进制） |
| 运行期配置开关 + 路由条件注册 | 重启生效 | 安全 | 低 | **采纳** |
| 独立进程/端口 | 进程级 | 安全 | 高 | 否决（违反单二进制） |
| 删除表/字段做回滚 | 破坏性 | 危险 | 中 | 否决 |

## 决策

- 配置：`search.enabled`（默认 true），环境变量 `BUJIC_SEARCH_ENABLED`。
- 关闭时：`/api/v1/search/*` 除 `/status` 外统一 404；前端侧栏隐藏入口；无后台任务（本模块没有常驻 goroutine）。
- 迁移：只 `AutoMigrate` 新表；不修改既有表；降级二进制不读取新表，数据保留。
- 模块内不注册 watcher、不启动定时器；清理任务在请求路径上顺带执行，关闭模块即停止。

## 代价

- 关闭需要重启（配置不热更新），可接受。
- 代码常驻，即使关闭也占二进制体积；在 NFR-12 预算内。
- 未来若要热开关，需要重新评估状态清理。

## 影响

- 回滚演练：升级 → 产生数据 → 降级二进制 → 启动 → 既有页面正常。
- 停用演练：关闭开关 → 侧栏无入口 → 既有整理/刮削不受影响。
